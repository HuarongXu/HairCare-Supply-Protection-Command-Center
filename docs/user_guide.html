🚀 快速启动

最简单的启动方式：

  1. 双击 update_and_start_matres.bat — 位于项目根目录。这个脚本会自动完成所有事情：拉取最新代码、创建 Python 虚拟环境、安装依赖、运行数据处理、启动看板服务。
  2. 等待命令行窗口显示启动信息 — 看到 Running on http://0.0.0.0:8050 表示成功。整个过程大约 1-3 分钟。
  3. 打开浏览器访问 — 本机 http://localhost:8050，或局域网 http://电脑IP:8050
💡
首次启动说明：首次运行需要安装 Python 依赖包，可能需要额外等待 2-5 分钟。之后的启动会快很多。
⚠️
前提条件：电脑需安装 Python 3.10+ 和 Git。如果没有，BAT 文件会提示安装。

📊 Demand Assumption

这是看板的默认首页，展示 Demand 需求假设与 Supply 保护的全景视图。

包含的数据表

表名内容数据来源
Demand System LBE需求系统 LBE 月度数据HC IDP HANA TD Report（Monthly + Weekly TP）
Demand System LBE IYALBE 与去年同期对比百分比LBE + Historical Shipment Data
Demand System LBE + Supply System Protection需求 + 供应保护合并数据LBE + Supply Protection 数据
Demand LBE + SSP IYA合并数据的同期对比HS 数据 + Historical Shipment Data
Supply Protection (PP + Base)供应保护按 Level1 汇总MatRes 工作簿
Supply Protection (HKTW + ESS)HKTW和ESS的供应保护MatRes 工作簿
Demand IYA by Quarter按季度的 IYA 对比月度数据按季度聚合

关键计算逻辑

  • LBE 取数：当前月取 Weekly(TP) 的 ER → LBE，SU 转 MSU（÷1000）；非当前月取 Monthly sheet
  • IYA 计算：IYA% = 当月值 / 去年同月值 × 100，分母为 0 或缺失时显示 -
  • HS 合并：Demand HS = Demand LBE + Supply Protection（Base → HS Base, PP → HS Promotion）
  • 时间窗口：当前季度 + 后续 2 个季度（共 9 个月）

📋 Project Details

按项目维度的详细分析页面，支持多条件筛选和下钻。

操作方式

  1. 选择 Role 筛选 — 页面顶部的 Role 按钮：ALL / NI / On Going / Cross Region
  2. 可选筛选 — Requester Email、MRP Element Indicator、Item Text 三个下拉筛选，均支持多选和搜索
  3. 关键词模糊搜索 — 在筛选栏最右侧输入关键词，对 Role / Item Text / MRP Element Indicator 进行模糊匹配（不区分大小写）
  4. 查看汇总 — Role × Item × Project 交叉汇总表，支持分页（每页 10 条）、排序、列头原生筛选
  5. 下钻明细 — 点击汇总表中任意行，下方显示对应的物料明细
  6. 导出明细 — 点击"下载全部明细"按钮导出 Excel

Total 行说明

汇总表下方有一个独立的 Total 行，显示跨所有分页的合计值（不受分页和排序影响，始终固定在底部）。模糊搜索时，Total 行会自动重新计算为筛选后结果的合计。

📈 Demand Data

TD 版本对比分析，帮助发现 Demand 版本之间的差异。

操作方式

  1. 查看主表 — TD Version Monthly Comparison：展示 Current / Previous / Gap 三行数据，按 Prod Line (Base / PP) 分行
  2. 点击 GAP 行 — 点击 GAP 行任意月份单元格，下方展开两个明细表
  3. Level2 GAP Details（左侧）— 按 Level2 维度的差异汇总，可排序
  4. GAP Difference Details（右侧）— 按物料的差异明细，默认按 GAP 升序排
  5. 导出 — 两个明细表都支持 Export 到 Excel
💡
颜色含义：GAP < 0 显示红色（减少），GAP > 0 显示绿色（增加）。

单元格计算器

在 Demand Data 和 Production Data 页面，可以使用 Ctrl+点击（Mac: Cmd+点击）多个表格单元格，右下角会自动弹出计算小工具，实时显示所选单元格数值的求和和已选数量。再次 Ctrl+点击已选单元格可取消选中，点击 ✕ 按钮清空所有选择。

🏭 Production Data

工厂生产数据，展示计划产量和实际进度。

两个子标签页

Production Data 页面分为 Summary 和 Detail by Brand/Size/Variant 两个子标签页。

Sub-tab 1: Summary

表维度说明

Table 2: By Plant / Level1 / Level2Plant + Level1 + Level2按工厂→分类→子分类 三级展开

Sub-tab 2: Detail by Brand/Size/Variant

生产数据关联 TD 报表维度标签，支持按多种维度聚合和筛选。

  • Group By 下拉框：选择聚合维度（默认 Plant / Brand / Size / Variant），可从 Plant、Brand、Lineup、Size、Type、NI/Conversion、Prod Line、Variant 中自由组合
  • 6 个筛选下拉框：Brand、Size、Variant、Plant、Lineup、Prod Line — 支持多选 + Select All
  • 数据列：MTD、Left Production、Current Month Total、以及未来月份列（当月列不显示，避免重复）
  • Total 行：底部自动附加汇总行

工厂分组

  • HP = 0386 + C810
  • XQ = 1864 + D352
  • TC = A868 + A673
  • GC Total = 以上所有工厂合计

当月拆分说明

当前月份列会拆分为 3 列：MTD（已完成）、Left Production（剩余计划）、Current Month（当月合计）

🧮 业务逻辑

角色映射规则

  • Email → Role 映射定义在 config/requester_roles.json
  • 支持 Email typo 自动修复（如 @pg,com → @pg.com）
  • 未匹配的 Email 归为 Others
  • UI 显示名：IOL → NI，CSP → On Going，CROSS REGION → Cross Region

Level1 映射规则

  • 来自 Level1 映射工作簿（Seg summary sheet）
  • 若映射缺失：Item Text = RM Material 的强制归到 Base，其他保留 "未映射"
  • 未映射数值接近 0 时自动隐藏

Production Volume 筛选规则

  • Categories / Members = 2.0Production/Receipts
  • Plant 非空、Material 非空
  • MRP Elements 仅保留 2.1Planned Orders 和 2.2Process Orders
  • Other 被排除（避免与 MTD 中 QM 重复计算）
  • 月份列动态展示（不固定 6 个月）

❓ 常见问题

Q: 浏览器显示 "127.0.0.1 refused to connect"

应用进程未启动或已退出。检查：
① 命令行窗口是否仍在运行
② 运行 netstat -ano | findstr :8050 检查端口
③ 重新双击 BAT 文件启动

Q: 看到的是旧数据

① Ctrl+Shift+R 强制刷新浏览器
② 检查是否有多个 Python 进程（任务管理器 → 结束所有 python.exe → 重启）
③ 去 Admin → Run Pipeline 重新运行数据处理

Q: Update & Restart 后应用没重启

如果应用是从 VS Code 终端启动的，os.execv 可能因终端断开而失败。
解决方案：关闭所有 Python 进程 → 双击 BAT 文件重新启动。

Q: git push 失败 (TLS / schannel 错误)

在 PowerShell 中使用重试命令：

$ok=$false; 1..3 | ForEach-Object {
  git -c http.version=HTTP/1.1 `
      -c http.schannelCheckRevoke=false `
      push origin main
  if ($LASTEXITCODE -eq 0) { $ok=$true; break }
  Start-Sleep -Seconds 2
}
if (-not $ok) { exit 1 }

Q: 找不到 Python

确认安装 Python 3.10+ 并勾选了 "Add to PATH"。
CMD 中运行 python --version 验证。
如果刚安装，需要重启 CMD / PowerShell 窗口。
