MatRes Dashboard — Board Logic Guide

Purpose: one-page handover document for new users. Covers page functions, source data, and calculation logic.
Updated: 2026-03-16 Main App: dashboards/matres_app.py Pipeline: scripts/matres_pipeline.py

1) End-to-End Data Flow

  • Raw files are read by scripts/matres_pipeline.py.
  • Pipeline writes standardized outputs to data/processed/.
  • Dashboard dashboards/matres_app.py loads processed CSVs through load_data_bundle().
  • UI refresh interval is 15 minutes and supports manual interaction-level drilldown.

3) Page-by-Page Functional Scope

Demand Assumption

  • Tables: Demand LBE, Demand LBE IYA, Demand HS, Demand HS IYA.
  • Supply Protection split tables: (PP + Base) and (HKTW + ESS).
  • Quarter view split into current quarter and next quarter IYA tables.

Supply Protection

  • KPI cards: total protection MSU, item count, PDE open alerts (coming 7 days).
  • Role trend chart and role-item matrix summary.
  • Monthly summary table and Past Due Alerts table.

Project Details

  • Role × Item × Project summary table.
  • Searchable multi-select filters: Requester Email, MRP Element Indicator.
  • Detail drilldown and full detail export.

Demand Data

  • Main table: TD Version Monthly Comparison.
  • Click GAP row to drive two detail tables: Level2 gap and item-level gap difference.
  • Both detail sections support export to Excel.

Production Data

  • Two tables: By Plant and By Plant / Level1 / Level2.
  • Current month split: MTD, Left Production, Current Month.
  • Total rows highlighted (HP/TC/XQ totals and GC Total).

4) Core Calculation Logic

MetricLogic
Demand LBE Monthly LBE values from HC IDP monthly summary; current month can use Weekly(TP) override logic from pipeline stage.
Demand HS Demand HS = Demand LBE + Supply Protection, with supply split mapped to Base and Promotion buckets.
IYA (monthly) IYA% = current value / last-year same-period baseline × 100; missing denominator shows placeholder.
Quarter IYA Quarter sums for LBE and HS; quarter IYA computed against same-quarter historical baseline.
Production tables Current month is split into MTD / Left / Current Month Total; monthly columns kept in YYYY-MM sequence with subtotal rows.
Supply Protection total For weekly email and summary usage, total can be aggregated across all months (FG + Material groups).

5) Operation Notes

  • Run pipeline first, then launch dashboard.
  • Keep config local and environment-specific (config/config.json should not be treated as shared public secret).
  • Recommended for release: use Git branch/tag strategy and deploy production machine from tagged version only.
